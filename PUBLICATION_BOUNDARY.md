# Publication boundary

This is a **public Backpack Battles-only repository**.

## Allowed public material

Only material directly related to the Backpack Battles AI Lab experiment may be published here, including:

- Backpack Battles patch notes and mechanic references
- strategy priors and build hypotheses
- decision-model logic
- experiment/run schemas
- anonymized Backpack Battles run results
- screenshots intentionally selected for public experiment documentation
- Custom GPT instructions and reproducibility material
- Backpack Battles community feedback and issue discussion

## Never publish here

Do not publish or derive repository content from unrelated private material, including:

- other projects or ventures
- private business operations
- CRMs or deal-flow data
- email or private messages
- personal contacts
- calendar data
- private documents
- database credentials, API keys, tokens or connection strings
- private connected-source data
- personal information unrelated to the Backpack Battles experiment

## Default rule

When there is any doubt whether information belongs to the Backpack Battles experiment, **do not publish it**.

Public artifacts should be generated from Backpack Battles-specific source material or the Backpack Battles experiment database, not from broader private workspace context.
